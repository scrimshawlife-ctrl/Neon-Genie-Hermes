# Neon-Genie-Hermes

Neon Genie is a governed Hermes skill for invention, product architecture, opportunity mining, fragmentation analysis, Zero-State execution loops, agentic service design, commercial modeling, evidence research, memetic testing, and Wayfinder-ready implementation handoffs.

## Skill package (v3.0.0)

Install by copying `neon-genie/` into your Hermes custom-skills directory.

| Path | Purpose |
|------|---------|
| `neon-genie/SKILL.md` | Kernel, router, authority, promotion ladder |
| `neon-genie/manifest.json` | Profiles, claim labels, modes |
| `neon-genie/profiles/` | Specialized profile contracts |
| `neon-genie/schemas/` | Output packet JSON schemas |
| `neon-genie/references/` | Capability map + golden tests |
| `neon-genie/templates/` | Request envelope |
| `neon-genie/tests/golden/` | Fixture expectations |

## Authority

Advisory only. Neon Genie may research, infer, generate, score, audit, and route. It does **not** spend, publish, modify repositories, execute irreversible workflows, or promote artifacts to canon without explicit downstream authorization.

## Example

```text
/neon-genie audit this project using product_architecture, commercial,
and wayfinder_handoff. Use Notion as canonical. Separate OBSERVED,
INFERRED, SPECULATIVE, and NOT_COMPUTABLE. Do not modify the repository.
```
